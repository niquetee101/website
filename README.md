    ## Responsive Design
The website was made responsive using CSS Flexbox layouts, relative sizing, and custom `@media` queries targeting screen widths up to 768px. Flexbox allows navigation links and card containers to adapt smoothly across different viewports, while responsive image properties (`max-width: 100%`) prevent photos from overflowing their containers. On mobile devices and smaller screens, media queries automatically stack the main navigation vertically, reduce grid sections down to a single column layout, and adjust font sizes, padding, and table containers to ensure optimal readability and user experience.
